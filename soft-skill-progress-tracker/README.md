# Soft Skill Progress Tracker

This Python project helps users track improvement in soft skills such as communication, teamwork, and confidence.

The project is focused on personal development and self-reflection.

---

## HOW TO RUN
1. Install Python
2. Open terminal in project folder
3. Run: python src/main.py

---

## PROJECT EXPLANATION

### main.py
Controls the menu and user interaction.

### skills.py
Handles adding and viewing skill improvement logs.

---

## DATA FIELDS
- Skill Name
- Description
- Date
- Difficulty
- Lesson Learned
